This example uses **chess-board** for the UI and **@pech/chess-core** for game logic: only legal moves are accepted, the position and legal-move highlights update after each move, and pawns reaching the last rank show the built-in promotion picker.

import ChessExample from '../../../components/ChessExample';

<ChessExample client:load />

Try it: drag a piece to a highlighted square, right-drag to draw an arrow, right-click (no drag) to toggle a circle, or Tab into the board and use the arrow keys + Enter to move without a mouse.

## How it works

The board is wired to chess-core in `onMove`: we resolve the move with `fromUci(position, uci)`, where `uci` is `from + to` plus an optional promotion letter. If that returns a move, we apply it with `makeMove`, then update the board and legal moves:

```ts
import { ChessBoard, STARTING_FEN, type PieceType } from '@pech/chess-board';
import { fromFen, toFen, getLegalMoves, makeMove, fromUci, toUci } from '@pech/chess-core';

// chess-board's promotion type is the full word ('queen'); UCI wants a
// single letter as the 5th character (e.g. "e7e8q").
const PROMO_TO_UCI: Record<PieceType, string> = {
  queen: 'q', rook: 'r', bishop: 'b', knight: 'n', king: '', pawn: '',
};

let position = fromFen(STARTING_FEN);
const board = new ChessBoard(container, {
  position: STARTING_FEN,
  draggable: true,
  promotionPicker: true,
  onMove(from, to, promotion) {
    const uci = from + to + (promotion ? PROMO_TO_UCI[promotion] : '');
    const move = fromUci(position, uci);
    if (!move) return false;

    const newPos = makeMove(position, move);
    board.setPosition(toFen(newPos));
    board.setLastMove(from, to);
    board.setLegalMoves(getLegalMoves(newPos).map((m) => toUci(m).slice(2, 4)));
    position = newPos;
    return true;
  },
});
board.setLegalMoves(getLegalMoves(position).map((m) => toUci(m).slice(2, 4)));
```

UCI format is `from + to` (e.g. `e2e4`), so the "to" square for highlights is `toUci(move).slice(2, 4)`. With `promotionPicker: true`, `onMove` receives the chosen piece as a third argument once the user picks — without it, `fromUci` would match whichever promotion variant `getLegalMoves` happens to list first.

Arrows, circles, and keyboard navigation don't need any wiring — they're handled entirely by the board itself and work the moment the board is created. See [Arrows & circles](/chess-board/guides/shapes/) and [Keyboard accessibility](/chess-board/guides/keyboard/).
